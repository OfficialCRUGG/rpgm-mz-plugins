# CRG_Core

This plugin provides various useful utility function used across the CRG plugin suite.

NOTE: This plugin adds *zero* noticable changes to your game. It is purely a utility plugin for other CRG plugins.

In the future, I might add small functionality that isn't big enough to warrant its own plugin, but once this is the case, it will be togglable and "OFF" by default.
